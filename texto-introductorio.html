01 ¿Qué es Git?

Git es un sistema de control de versiones que permite registrar los cambios realizados en un proyecto. Los commits permiten guardar cada modificación y conocer cómo evolucionó el trabajo a lo largo del tiempo.

02 ¿Qué es GitHub? (Diferencia clave con Git)

GitHub es una plataforma que permite almacenar, compartir y colaborar en proyectos gestionados con Git. En síntesis: Git registra los cambios y GitHub permite alojar y compartir los proyectos.

03 Uso educativo: Los Commits como evidencia en tu e-Portfolio

En Programación I, los estudiantes pueden utilizar GitHub para crear un e-portfolio donde reúnan ejercicios y proyectos. Los commits permiten mostrar el proceso de aprendizaje y no solamente el resultado final.

Ejemplo académico de trazabilidad mediante commits en Programación I:
commit #1 → "Creo el programa inicial"
commit #2 → "Corrijo un error"
commit #3 → "Agrego una nueva función"

Introducción a Git, GitHub y los e-portfolios

En el aprendizaje de programación, Git y GitHub son herramientas que permiten organizar, guardar y compartir los proyectos desarrollados durante una materia.

Git es un sistema de control de versiones que registra los cambios realizados en los archivos de un proyecto. Por ejemplo, un estudiante puede guardar diferentes versiones de un programa y consultar qué modificaciones realizó a lo largo del tiempo.

GitHub es una plataforma que permite almacenar proyectos gestionados con Git en repositorios en línea. Además, facilita compartir los trabajos, colaborar con otras personas y mostrar proyectos realizados.

Estas herramientas también pueden utilizarse para construir un e-portfolio académico. Un estudiante puede crear un repositorio donde reúna sus ejercicios, proyectos y actividades de Programación I. Los diferentes cambios registrados mediante commits permiten observar cómo evolucionó su trabajo.

Por ejemplo, un estudiante puede comenzar subiendo un programa sencillo, luego corregir errores y posteriormente agregar nuevas funciones. Cada etapa queda registrada, permitiendo visualizar parte del proceso de aprendizaje y no solamente el resultado final.

De esta manera, Git y GitHub pueden convertirse no solo en herramientas utilizadas para programar, sino también en recursos para documentar, organizar y mostrar el aprendizaje desarrollado durante una asignatura.

Trazabilidad de Prompts

Prompts Utilizados en ChatGPT

1. Prompt Inicial 
Actúa como docente universitario de Programación I. Genera un texto introductorio sobre Git y GitHub dirigido a estudiantes con conocimientos básicos de programación. Explica qué son, para qué sirven y cómo pueden utilizarse para construir un e-portfolio académico. Utiliza lenguaje claro, ejemplos sencillos y evita terminología técnica innecesaria.
2. Prompt de Refinamiento 
Revisa el texto anterior y mejóralo. Diferencia claramente Git de GitHub, explica cómo los commits permiten documentar el proceso de aprendizaje y relaciona GitHub con la construcción de un e-portfolio. Utiliza lenguaje accesible para estudiantes universitarios de Programación I, incorpora un ejemplo académico y organiza el contenido mediante subtítulos y párrafos breves.

Principios de Uso Responsable (UNESCO)

  • • Transparencia: Se informa explícitamente cuándo un contenido fue generado o asistido con IA.
  • • Responsabilidad: El equipo docente revisa y valida la exactitud conceptual antes de su publicación.
  • • Mitigación de Sesgos: Evaluación crítica para evitar imprecisiones o generalizaciones.
  • • Equidad y Privacidad: Sin inclusión de datos personales o sensibles de estudiantes en los prompts.
